# Restomatics Website

Static, no-cost Version 1 website for Restomatics.

## Included

- Emergency mitigation and property readiness homepage
- Property Hardening & Loss-Prevention Walkthrough request page
- Click-to-call, SMS, and email actions
- Mobile-responsive layout
- Basic SEO metadata, sitemap, and robots file

## Publish free with GitHub Pages

1. Merge the `restomatics-site-v1` pull request into `main`.
2. In GitHub, open **Settings → Pages**.
3. Under **Build and deployment**, choose **Deploy from a branch**.
4. Select branch `main` and folder `/ (root)`, then save.
5. GitHub will publish a temporary address such as `https://restomatics.github.io/Restomatics/`.

## Connect restomatics.com

After GitHub Pages is live:

1. In **Settings → Pages**, enter `restomatics.com` under **Custom domain** and save.
2. At the domain registrar, add the DNS records GitHub specifies for the apex/root domain and `www`.
3. Wait for DNS verification, then enable **Enforce HTTPS** in GitHub Pages.
4. Verify these pages load securely:
   - `https://restomatics.com/`
   - `https://restomatics.com/walkthrough.html`

Do not print a QR code until the custom domain is connected and confirmed stable.
